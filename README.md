# SOUL on life — Catálogo de espaços

Site estático do catálogo de espaços para eventos da SOUL on life.

Site publicado: https://kottwitz.github.io/soul-on-life-catalogo-eventos/

## Publicação

O GitHub Actions publica automaticamente o conteúdo desta pasta no GitHub Pages
a cada push para a branch `main`. A origem de publicação do repositório está
configurada como **GitHub Actions**.

O site inclui as fotos e o catálogo em PDF disponíveis para download.
